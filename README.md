# VariLink

Variation and change management tool for cost teams, built for the Cost Code AI Challenge 2026.

Open `index.html` or the hosted page. The tool runs in the browser. Calculations use coded rules, and AI is optional.

- One record from DCR to CR to VO, with price moves explained
- Lump sum and re-measured quantity rules
- Rates from the BOQ, similar items, derived rates or new build-ups
- Contractor against AAA comparison
- Excel assessment and change log with live formulas
- Cost report import, processed in the browser

The included project is fictional. Never commit client data to this repository.

`npm install`, `npm test`, `npm run build`
